# 🔧 Hardware Components

The Intelligent Voice-Operated Smart Wheelchair is built using a combination of embedded computing platforms, AI peripherals, sensors, and motor control modules. Each hardware component is selected to ensure reliable real-time processing, autonomous navigation, and efficient power management.



---

## 🖥 Raspberry Pi 4 Model B

The Raspberry Pi 4 serves as the primary processing unit of the system. It executes the high-level application logic, including offline speech recognition, computer vision, AI-based navigation, and communication with the ESP32 controller.

**Specifications**

- Quad-Core ARM Cortex-A72 (64-bit) Processor @ 1.5 GHz
- 4 GB RAM
- Raspberry Pi OS (64-bit)
- CSI Camera Interface
- USB 3.0 & USB 2.0 Ports
- 40-Pin GPIO Header
- Integrated Wi-Fi & Bluetooth

**Role in the Project**

- Offline Voice Recognition (Vosk STT)
- Computer Vision Processing
- AI Decision Making
- Navigation Logic
- Communication with ESP32

---

## 🎤 ReSpeaker 2-Mic HAT

The ReSpeaker 2-Mic HAT provides high-quality far-field audio capture for reliable speech recognition. It enhances voice signals using noise suppression and acoustic echo cancellation before forwarding the audio stream to the Raspberry Pi.

**Specifications**

- Dual MEMS Microphones
- I2S Audio Interface
- Far-field Voice Capture
- Acoustic Echo Cancellation
- Noise Suppression
- Compatible with Raspberry Pi 40-Pin Header

**Role in the Project**

- Voice Input Acquisition
- Audio Signal Enhancement
- Speech Command Capture

---

## 📷 Raspberry Pi Camera Module 3 NoIR

The Camera Module 3 NoIR captures continuous real-time video for computer vision tasks. The NoIR (No Infrared Filter) variant enables improved performance in low-light environments.

**Specifications**

- 12 MP Sony IMX708 Sensor
- Autofocus Support
- CSI Interface
- HDR Capability
- NoIR (Infrared Sensitive)

**Role in the Project**

- Real-Time Video Streaming
- Object Detection
- Path Recognition
- Obstacle Identification

---

## ⚙ ESP32 Development Board

The ESP32 functions as the dedicated low-level embedded controller responsible for motor control, sensor monitoring, and real-time execution of navigation commands received from the Raspberry Pi.

**Specifications**

- Dual-Core Tensilica LX6 Processor
- 240 MHz Clock Frequency
- Wi-Fi & Bluetooth
- PWM Support
- UART, SPI, I2C Interfaces
- Low Power Consumption

**Role in the Project**

- Motor Control
- Sensor Data Acquisition
- PWM Signal Generation
- Safety Monitoring

---

## 🔋 L298N Dual H-Bridge Motor Driver

The L298N motor driver controls the speed and direction of the wheelchair motors using PWM signals generated by the ESP32.

**Specifications**

- Dual H-Bridge Driver
- Operating Voltage: 5V–35V
- Maximum Output Current: 2 A per Channel
- Bidirectional Motor Control
- PWM Speed Control

**Role in the Project**

- Motor Direction Control
- Speed Regulation
- Differential Drive Control

---

## ⚙ DC BO Gear Motors

Four high-torque DC BO geared motors provide the driving force for the wheelchair and enable smooth differential steering.

**Specifications**

- Operating Voltage: 6V–12V
- Metal Gearbox
- High Torque Output
- Low Noise Operation

**Role in the Project**

- Wheelchair Propulsion
- Forward/Reverse Motion
- Left & Right Turning

---

## 📡 Ultrasonic Sensor (HC-SR04)

The ultrasonic sensor continuously measures the distance between the wheelchair and surrounding obstacles using ultrasonic waves.

**Specifications**

- Detection Range: 2 cm – 400 cm
- Operating Voltage: 5V
- Accuracy: ±3 mm
- Ultrasonic Frequency: 40 kHz

**Role in the Project**

- Distance Measurement
- Front Obstacle Detection
- Collision Prevention

---

## 🚧 Infrared (IR) Sensor

The IR sensor detects nearby obstacles and assists in short-range navigation, particularly for edge and close-proximity detection.

**Specifications**

- Operating Voltage: 3.3V–5V
- Adjustable Detection Range
- Digital Output
- Low Power Consumption

**Role in the Project**

- Short-Range Obstacle Detection
- Edge Detection
- Safety Assistance

---

## 🔋 Battery Pack (Power Supply)

A rechargeable battery pack provides portable power for the Raspberry Pi, ESP32, sensors, and motor drivers.

**Specifications**

- Rechargeable Battery
- 12V Output
- Portable Design
- High Current Capability

**Role in the Project**

- Main Power Source
- Portable Operation

---

## ⚡ DC-DC Voltage Regulator

The voltage regulator converts the battery voltage into stable output voltages required by different hardware modules.

**Specifications**

- Buck Converter
- Input Voltage: 6V–24V
- Output Voltage: Adjustable (5V Typical)
- High Conversion Efficiency

**Role in the Project**

- Voltage Regulation
- Stable Power Distribution
- Component Protection
